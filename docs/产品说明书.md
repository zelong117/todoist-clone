## 1. 产品概述

**Todoist Clone** 是一款融合人工智能助手的新一代任务管理应用。它不仅提供传统待办清单的核心功能，更通过内置 AI 助手为用户提供智能任务分析、优先级建议、效率洞察等高级功能，帮助用户更高效地管理时间和精力。

### 产品定位
- **目标用户**：个人效率管理者、小型团队、自由职业者
- **核心价值**：用 AI 让任务管理更智能，让每一天都有方向
- **差异化**：内置 AI 助手实时分析任务数据，提供个性化建议

### 产品愿景
> "让每个人都能拥有一个懂你的 AI 工作助手"

## 4. 数据模型

### 核心实体

```
User ──┬── Project ──┬── Section
       │             └── Task ──┬── Comment
       ├── Label               └── PomodoroSession
       └── Task (inbox)
```

### 数据表

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| users | 用户 | id, email, name, password_hash, role |
| projects | 项目 | id, user_id, name, color, use_pomodoro |
| tasks | 任务 | id, user_id, project_id, title, priority, due_date, labels |
| sections | 分组 | id, project_id, name, sort_order |
| labels | 标签 | id, user_id, name, color |
| comments | 评论 | id, task_id, user_id, content |
| pomodoro_sessions | 番茄钟 | id, task_id, user_id, mode, started_at, completed |

## 5. API 接口

### 认证
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/register | 注册 |
| POST | /api/auth/login | 登录 |
| GET | /api/auth/me | 获取当前用户 |

### 任务
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/tasks | 获取所有任务 |
| POST | /api/tasks | 创建任务 |
| PUT | /api/tasks/:id | 更新任务 |
| DELETE | /api/tasks/:id | 删除任务 |
| POST | /api/tasks/:id/complete | 切换完成状态 |

### 项目
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/projects | 获取所有项目 |
| POST | /api/projects | 创建项目 |
| PUT | /api/projects/:id | 更新项目 |
| DELETE | /api/projects/:id | 删除项目 |

### 其他
- 标签 CRUD: `/api/labels/*`
- 评论: `/api/comments/*`, `/api/tasks/:id/comments`
- 番茄钟: `/api/pomodoro/start`, `/api/pomodoro/stop`, `/api/pomodoro/sessions`
- 管理后台: `/api/admin/stats`, `/api/admin/users`

## 6. 安全特性

| 安全措施 | 实现方式 |
|----------|----------|
| 密码加密 | bcryptjs (12 rounds) |
| JWT 认证 | 7天有效期，环境变量密钥 |
| 管理员权限 | requireAdmin 中间件 |
| API 限流 | 15分钟/20次（auth 路由） |
| 字段白名单 | PUT 路由防批量赋值 |
| 输入验证 | 邮箱格式、密码长度、字段长度 |
| 数据隔离 | 所有查询加 userId 过滤 |
| CORS 限制 | 指定源访问 |
| 请求体限制 | 1MB 上限 |

## 7. 部署指南

### 环境要求
- Node.js 20+
- npm 或 yarn
- 腾讯云/阿里云服务器（推荐 Ubuntu 22.04）

### 快速部署

```bash
# 1. 克隆代码
git clone https://github.com/zelong117/todoist-clone.git
cd todoist-clone

# 2. 安装前端依赖并构建
npm install && npm run build

# 3. 安装后端依赖
cd server && npm install

# 4. 配置环境变量
cat > .env << EOF
PORT=3001
JWT_SECRET=你的随机密钥
CORS_ORIGIN=http://你的域名
NODE_ENV=production
EOF

# 5. 启动服务
npm install -g pm2
pm2 start index.js --name todoist-api
pm2 serve ../dist 80 --name todoist-web --spa
pm2 save && pm2 startup
```
