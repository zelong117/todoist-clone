### 2.2 状态管理 (Zustand)

```typescript
// store.ts 核心结构
interface AppState {
  // 数据
  tasks: Task[];
  projects: Project[];
  sections: Section[];
  labels: Label[];
  comments: Comment[];

  // UI 状态
  activeView: ActiveView;
  selectedProjectId: string | null;
  selectedTaskId: string | null;
  viewMode: 'list' | 'board' | 'calendar';
  darkMode: boolean;

  // 番茄钟状态
  timerMode: TimerMode;
  timerStatus: TimerStatus;
  timerSeconds: number;

  // Actions (async, 调用后端 API)
  addTask: (task) => Promise<void>;
  updateTask: (id, updates) => Promise<void>;
  deleteTask: (id) => Promise<void>;
  toggleComplete: (id) => Promise<void>;
  // ... 更多 actions
}
```

**关键设计**：
- 所有写操作先调 API，成功后更新本地状态
- API 失败时 fallback 到本地操作（离线兼容）
- 使用 `persist` middleware 自动同步到 localStorage

### 2.3 API 客户端 (api.ts)

```typescript
// 统一请求封装
async function request<T>(path: string, options?: RequestInit): Promise<T> {
  const token = localStorage.getItem('todoist_token');
  const headers = {
    'Content-Type': 'application/json',
    ...(token && { Authorization: `Bearer ${token}` }),
  };
  const response = await fetch(`${API_URL}${path}`, { ...options, headers });
  if (!response.ok) throw new Error((await response.json()).error);
  return response.json();
}

// 导出的 API 模块
export const authAPI = { register, login, me };
export const tasksAPI = { getAll, create, update, delete, complete };
export const projectsAPI = { getAll, create, update, delete };
export const labelsAPI = { getAll, create, update, delete };
export const pomodoroAPI = { getSessions, start, stop };
```

## 5. 安全设计

### 5.1 认证流程

```
注册:
  POST /api/auth/register
  → 验证输入 → bcrypt.hash(password, 12) → INSERT INTO users
  → jwt.sign({ id, role }, JWT_SECRET, { expiresIn: '7d' })
  → 返回 { token, user }

登录:
  POST /api/auth/login
  → SELECT user WHERE email = ? → bcrypt.compare(password, hash)
  → jwt.sign({ id, role }, JWT_SECRET, { expiresIn: '7d' })
  → 返回 { token, user }

请求认证:
  Authorization: Bearer <token>
  → jwt.verify(token, JWT_SECRET) → req.user = decoded
  → next()
```

### 5.2 安全措施

| 措施 | 实现 |
|------|------|
| 密码存储 | bcryptjs, 12 rounds |
| Token | JWT, 7天有效期, env 变量密钥 |
| 限流 | express-rate-limit, 20次/15分钟 |
| 输入验证 | 前后双重验证, 字段长度限制 |
| 批量赋值 | 字段白名单 (pick 函数) |
| 数据隔离 | 所有查询加 user_id 过滤 |
| CORS | 指定源访问 |
| Body 限制 | 1MB 上限 |
